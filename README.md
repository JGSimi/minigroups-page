# Mini Groups Studio

Website developed for **Mini Groups Studio**, designed to showcase the studio's games and provide information about its projects.

The application includes a responsive game catalog, individual game information and integration with a backend API.

## Tech Stack

### Frontend

- React
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- TanStack Query

### Backend

- Node.js
- Express
- TypeScript
- REST API

## Features

- Responsive game showcase
- Game details
- Favorites with local persistence
- Light and dark themes
- Data fetched through a dedicated backend API
- Contact integration
- SEO and accessibility improvements

## Running Locally

Install and run the frontend:

```bash
npm install
npm run dev
```

The backend is available inside the `backend` directory:

```bash
cd backend
npm install
npm run dev
```
